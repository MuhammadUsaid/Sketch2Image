
# Sketch2Image: Bringing Sketches to Life with Generative AI

## Project Overview

Sketch2Image is a generative AI project that transforms
hand-drawn sketches into visually compelling images.

The system uses pretrained diffusion models and
structural conditioning to preserve the main composition
of an input sketch while adding realistic visual details.

## Objectives

- Transform sketches into generated images.
- Preserve the structure of the original sketch.
- Explore text-guided image generation.
- Experiment with different generation parameters.
- Evaluate the quality of generated results.

## Technologies

- Python
- PyTorch
- Hugging Face Diffusers
- Stable Diffusion
- ControlNet
- OpenCV
- Gradio

## Project Structure

- data/: Original and processed sketches
- outputs/: Generated images and comparisons
- notebooks/: Experiments
- src/: Main implementation
- docs/: Documentation
